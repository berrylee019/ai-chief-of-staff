# 🧠 비서실장 대시보드 — 설치·배포 안내

한 줄 지시를 넣으면 **🧠 비서실장(총괄)** 이 업무를 나누고, **AI 직원 3인**이 각자 일한 뒤,
**최종 브리핑 + 직원별 보고서 + 실시간 API 비용(원/달러)** 을 한 화면에 보여 주는 Streamlit 앱입니다.
내 PC 없이 **스마트폰 브라우저만으로** GitHub에 올리고 Streamlit Community Cloud(무료)에 배포하면,
언제 어디서든 접속하는 **나만의 주소(URL)** 가 생깁니다.

---

## 0. 폴더 안의 파일 4개

| 파일 | 역할 |
|---|---|
| `app.py` | 대시보드 본체 (화면·비서실장·직원 3인·비용 계산·다운로드) |
| `requirements.txt` | 앱이 쓰는 패키지 목록 (배포할 때 자동 설치됨) |
| `README.md` | 지금 읽고 계신 이 안내서 |
| `.gitignore` | API 키 파일(`.streamlit/secrets.toml`)이 깃허브에 올라가지 않게 막는 안전장치 (선택이지만 권장) |

```
ai-chief-of-staff/
├── app.py
├── requirements.txt
├── README.md
└── .gitignore
```

> `.gitignore` 는 스트림릿 클라우드 배포에는 없어도 되지만, 나중에 PC에서 직접 실행할 때
> API 키가 깃허브에 올라가는 사고를 막아 줍니다. 휴대폰에서 숨김 파일 업로드가 어려우면 건너뛰어도 됩니다.

## 1. 무엇이 들어 있나 (화면 구성)

| 구성원 | 하는 일 | 화면 표시 |
|---|---|---|
| 🧠 **비서실장(총괄)** | 한 줄 지시를 JSON으로 분석 → 꼭 필요하면 확인 질문 2~3개 → 직원별 지시 배분 → 마지막에 결과 종합 | 업무 분배 내용 펼쳐 보기, 최종 브리핑 |
| 🔍 **시장조사·리서치** | 지원사업 공고, 시장 규모, 경쟁사·가격, 규제·유통 조사. **Tavily 키가 있으면 실제 웹 검색 결과를 출처와 함께** 사용 | 요약표 + 출처 링크 |
| 📄 **사업계획·문서** | 리서치 결과를 바탕으로 지원사업 계획서 초안, B2B 제안서, 손익·예산표 | 마크다운 문서 |
| ✉️ **영업·콘텐츠** | 영문/국문 영업 메일, 팔로업 메일, 블로그·유튜브 대본 | 메일·대본 초안 |

- **진행 로그**: 직원마다 `🔍 … 작업 중 → 완료` 상태 창이 실시간으로 바뀝니다.
- **실시간 비용**: API가 돌려준 입력/출력 토큰 수 × 모델 단가 × 환율(기본 **1,400원/USD**)을 계산해
  사이드바에 **원(₩)과 달러($)** 로 계속 갱신합니다.
- **결과물 내려받기**: 전체 보고서를 **`.md` 파일**로, 직원별 보고서를 **`.zip`** 으로 저장할 수 있습니다.
  `.md` 파일은 노션·구글 문서·한글에 그대로 붙여넣을 수 있습니다.
- **🧪 데모 모드**: API 키가 없어도 버튼 하나로 화면 전체를 미리 체험할 수 있습니다(예시 데이터).

## 2. 준비물 (10~20분)

1. **GitHub 계정** — 없으면 <https://github.com> 에서 무료 가입 (스마트폰 가능).
2. **Streamlit 계정** — <https://share.streamlit.io> 에서 **Continue with GitHub** 로 로그인하면 자동 가입.
3. **AI API 키 1개** — OpenAI 또는 Anthropic(Claude) 중 **하나만** 있으면 됩니다.

| 제공사 | 키 발급 주소 | 메뉴 | 최소 충전 |
|---|---|---|---|
| OpenAI | <https://platform.openai.com> | API keys → Create new secret key | 보통 $5부터 |
| Anthropic (Claude) | <https://console.anthropic.com> | API Keys → Create Key | 보통 $5부터 |

4. **(선택) Tavily 키** — <https://tavily.com> 가입 후 무료 키 발급 (월 1,000회 무료).
   없어도 앱은 돌아가며, 리서치 담당이 **자체 지식으로 작성하고 한계를 명시**합니다.

> 💡 **처음에는 OpenAI의 `gpt-4o-mini`** 를 권합니다. 가장 저렴하면서 이 정도 업무에는 충분합니다.
> 데모 기준 한 번 작업(6회 호출)에 1~5원 수준이고, 실제로 길게 쓰면 수십~수백 원 정도입니다.

## 3. GitHub에 파일 3개 올리기 (스마트폰 가능)

### 3-1. 저장소 만들기
1. 스마트폰 브라우저에서 <https://github.com> 로그인
2. 오른쪽 위 **`+` → New repository**
3. **Repository name**: `ai-chief-of-staff`
4. **Private** 선택 (권장 — 코드와 설정을 남에게 보이지 않게)
5. **Add a README file** 체크 → **Create repository**

### 3-2. 파일 올리기 (가장 쉬운 방법: 업로드)
1. 새로 만든 저장소 화면에서 **Add file → Upload files**
2. `app.py`, `requirements.txt`, `README.md` 세 파일을 선택해 올립니다.
   (`.gitignore` 는 휴대폰에서 안 보일 수 있으니, 없으면 넘어가셔도 됩니다.)
   - 이미 `README.md` 가 있으므로 덮어쓰기 됩니다(문제 없음).
   - 파일은 채팅으로 받은 파일을 휴대폰에 내려받아 두면 됩니다.
3. 아래 **Commit changes** 초록 버튼을 누릅니다.

> 📱 **붙여넣기로 만들고 싶다면**: **Add file → Create new file** → 파일명 `app.py` 입력 →
> 코드 전체를 붙여넣기 → **Commit changes**. 긴 코드는 휴대폰에서 붙여넣기가 불편하니
> 위의 **Upload files** 방식을 권합니다.

### 3-3. 잘 올라갔는지 확인
저장소 첫 화면에 `app.py`, `requirements.txt`, `README.md` 세 파일이 보이면 성공입니다.
(`.gitignore` 는 기본으로 숨김 처리되어 안 보일 수 있습니다.)

## 4. Streamlit Community Cloud에 배포하기 (무료)

1. 스마트폰 브라우저에서 <https://share.streamlit.io> 접속
2. **Continue with GitHub** → GitHub 로그인 → **Authorize**
3. **Create app** (또는 **New app**) → **Deploy a public app from GitHub** 선택
4. 아래 4칸을 채웁니다.

| 칸 | 넣을 값 |
|---|---|
| Repository | `본인아이디/ai-chief-of-staff` |
| Branch | `main` |
| Main file path | `app.py` |
| App URL (원하는 주소) | 예: `berry-chief` → `https://berry-chief.streamlit.app` |

5. **Deploy** 를 누르고 2~5분 기다립니다. (첫 배포는 패키지 설치 때문에 조금 걸립니다.)
6. 화면에 대시보드가 뜨면 성공이고, 위에서 정한 **나만의 주소**가 계속 유지됩니다.

> ⚠️ **무료 플랜의 특징**: 접속이 한동안 없으면 앱이 **잠들고**, 다시 열면 30초~1분 안에 자동으로 깨어납니다.
> 주소는 그대로이고 데이터도 그대로입니다. "항상 즉시 열려야" 한다면 유료 서버가 필요합니다.

## 5. API 키 넣기 (Secrets — 코드에 키를 쓰지 마세요)

배포가 끝나면 키를 넣어 줍니다.

1. 앱 화면 오른쪽 아래 **⋮ (점 3개) → Settings** → **Secrets**
2. 아래 형식으로 붙여넣고 **Save** (필요한 줄만 남겨도 됩니다)

```toml
# OpenAI를 쓸 때
OPENAI_API_KEY = "sk-여기에-발급받은-키"

# Anthropic(Claude)을 쓸 때
ANTHROPIC_API_KEY = "sk-ant-여기에-발급받은-키"

# 웹 검색(Tavily)을 쓸 때 — 선택
TAVILY_API_KEY = "tvly-여기에-발급받은-키"

# 환율을 바꾸고 싶을 때 — 선택 (기본 1400)
KRW_PER_USD = "1400"
```

3. 저장 후 **Reboot app**(앱 재시작)을 누릅니다.
4. 이제 앱 사이드바의 **API 키** 칸이 자동으로 채워집니다. (화면에서 직접 입력해도 됩니다 — 새로고침하면 지워집니다.)

> 🔐 **보안 3가지**
> - 키는 **절대 `app.py` 안에 직접 쓰지 마세요.** 깃허브에 올라가면 남이 볼 수 있습니다.
> - 저장소는 **Private** 을 권합니다.
> - 키가 노출된 것 같으면 제공사 콘솔에서 **즉시 삭제하고 새로 발급**하세요.

## 6. 사용법 (매일 이렇게)

1. 사이드바에서 **제공사 · 모델** 확인 (처음엔 기본값 그대로)
2. **🧪 데모 모드**가 켜져 있으면 끕니다.
3. 가운데 입력창에 **한 줄로 지시**를 씁니다. (또는 예시 버튼을 눌러 채우기)

예시 지시:
- "2027년 예비창업패키지 지원사업 신청용 계획서 초안을 만들어 줘. 예산은 5천만 원 규모야."
- "중소기업 5곳에 보낼 AI 문서 자동화 외주 제안서와 영업 메일을 준비해 줘."
- "미국 로봇회사 문워커스 에어로의 국내 총판 수익성을 조사하고 제안 메일을 써 줘."
- "경매 물건 2건을 비교하는 투자 검토 보고서를 만들어 줘. 예산은 1억 5천만 원."

4. **🚀 실행** → 비서실장이 필요하면 **확인 질문 2~3개**를 띄웁니다. 답을 적고 **✅ 답변 반영해서 실행**.
5. 직원들이 순서대로 일하는 진행 창이 보이고, 끝나면 **최종 브리핑**이 나옵니다.
6. **⬇️ 전체 보고서 내려받기 (.md)** 또는 **🗜️ 직원별 파일 (.zip)** 로 저장합니다.
7. **🆕 새 작업 시작** 으로 다음 지시를 넣습니다.

### 직원을 안 쓰고 싶을 때
비서실장이 지시에 필요 없는 직원은 자동으로 `⏸️ 배정하지 않음` 으로 둡니다.
강제로 조정하고 싶으면 **`app.py` 의 `CHIEF_SYSTEM`** 프롬프트에 규칙을 한 줄 추가하면 됩니다.

## 7. 비용 관리 요령

| 항목 | 방법 |
|---|---|
| 모델 | 처음엔 `gpt-4o-mini` / `claude-haiku-4-5` (가장 저렴) |
| 사용 한도 | OpenAI: Billing → **Limits** 에서 월 한도(예: $10) 설정. Anthropic도 동일 |
| Tavily | 무료 월 1,000회. 리서치 1회에 검색 3회 사용 |
| 환율 | 사이드바에서 바꿀 수 있습니다. 기본 1,400원 |
| 화면 비용 | **예상치**입니다. 실제 청구액과 1~2% 차이날 수 있습니다 |

> 단가가 바뀌면 `app.py` 위쪽의 **`MODELS`** 표만 고치면 됩니다.
> 모델을 추가하려면 같은 형식으로 한 줄 넣으면 사이드바 목록에 자동으로 나타납니다.

## 8. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| `Oh no.` 화면 / 배포 실패 | 앱 화면 **⋮ → Manage app → 로그** 확인. 대개 `requirements.txt` 누락 또는 파일명 오타 |
| `ModuleNotFoundError: streamlit` | `requirements.txt` 가 저장소 최상단에 있는지 확인 → **Reboot app** |
| "API 키 인증에 실패했습니다" | Secrets 이름이 `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` 인지, 결제(크레딧)가 있는지 확인 → Reboot |
| "크레딧이 부족합니다" | 제공사 콘솔에서 결제 수단·잔액 확인 |
| "선택한 모델을 사용할 수 없습니다" | 사이드바에서 다른 모델 선택 (계정에 따라 일부 모델이 막혀 있을 수 있음) |
| 앱이 안 열리고 계속 로딩 | 무료 플랜이 잠든 상태. 30초~1분 기다리거나 새로고침 |
| 결과가 영어로 나옴 | 입력 지시에 "한국어로 작성" 을 넣어 보세요 |
| 코드를 고쳤는데 그대로 | GitHub에 **Commit** 했는지 확인. Streamlit이 자동 재배포합니다(1~2분) |

## 9. 코드를 고치고 싶을 때 (자주 쓰는 위치)

| 바꾸고 싶은 것 | 위치 (`app.py`) |
|---|---|
| 모델·단가표 | `MODELS = { ... }` |

| 확인 질문 개수 | `CHIEF_SYSTEM` 의 "최대 3개" 부분 |

## 10. (선택) 내 컴퓨터에서 직접 실행

PC가 있을 때만 해당됩니다. 스마트폰만으로도 3~5단계로 충분합니다.

```bash
cd ai-chief-of-staff
python3 -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# API 키를 파일로 넣는 방법 (권장)
mkdir -p .streamlit
printf 'OPENAI_API_KEY = "sk-..."\nTAVILY_API_KEY = "tvly-..."\n' > .streamlit/secrets.toml

streamlit run app.py
```

브라우저에서 <http://localhost:8501> 이 열립니다.

> `.streamlit/secrets.toml` 은 **절대 GitHub에 올리지 마세요.** (`.gitignore` 에 `.streamlit/` 를 추가)
